# 新W5000手動プレイ候補

旧formal/D/Eとは別の試遊用候補。12時間バランス完成版ではありません。

## 起動

Node.js 22.13以降とPython 3.12以降を用意し、リポジトリ全体をcloneしてください。

```powershell
cd first-prestige-playtest
npm ci
npm run dev -- --port 4173
```

http://localhost:4173/ を開き「開始」。計算APIは127.0.0.1:8765です。
Pythonを指定する場合は起動前に`CODEX_PYTHON`環境変数を設定できます。

## 操作

- カード選択権はRun内で蓄積。「選択」から3択を開く。閉じても手札は保持。
- カード選択・バックパック・設定を開いても戦闘継続。一時停止は設定から手動。
- 武器取得時は全装備を一覧比較し「装備／保管／分解」を選択。
- 鞄内では装備／保管枠へドラッグ。炉へドロップすると即分解（確認なし）。
- 所持カードはクリックで説明表示。レアリティは色と名称で表示。
- 死亡後は停止。DPを購入し「再挑戦」で再開。未選択カードは死亡時破棄。

保存は未実装です。サーバー再起動・初期化で進行を失います。
ブラウザを複数開くと同じサーバーセッションを共有します。
Core/UB/Finale・全遺物・武器固有・スマホ専用UIは未接続。
候補値と接続境界は`../docs/NEW_W5000_PLAY_CANDIDATE.md`を参照。
