# 新W5000装備 初版候補（2026-10-03）

旧formal W10000、Variant D/E、w5000_v1既定、旧W1–500プレイテストは変更しない。
今回の独立実装は個体・装備・保管・強化・分解・同名処理・状態シリアライズのみ。
戦闘接続、Drop、UI、ファイルへの永続保存、DP保管拡張購入は未実装。

## 会話で決めた初版境界

- 武器装備1＋保管5、遺物装備3＋保管5。装備は保管数に含めない。
- 満杯時は手動選択。受領APIは満杯を拒否して個体を消さない。UIは未取得候補を別途保持する必要がある。
- 品質: 遺物は1.00固定。武器は本体ATKに作用、Affixとは分離（計算接続は後続）。
- 強化: +1/2/3は基準×1.08/1.16/1.24、コスト4/9/16。固有効果の整数・特殊ルールは強化対象外。
- 遺物分解C1/U3/R6＋実消費強化素材50%返還、端数切り捨て。
- 武器分解は既存候補C1/U3/R8/E20/L50を再利用。強化返還も50%の候補。
- 死亡で武器装備・保管を失い、通常分解価値50%を回収。遺物・素材・保管拡張は保持。
- Prestigeで個体・両素材・強化・重複・保管拡張をリセット、各保管5へ戻す。
- 同名遺物: 交換（旧品分解、強化非継承）、重複強化（固有正数値の基準+2%/個、10回）、素材化。整数・特殊効果とAffixは重複強化対象外。
- W100初到達でCommon学習レンズXP+10%、W500..4500の500Wave刻み初回報酬でランダム遺物。死亡後保持、Prestigeで報酬履歴リセット（報酬接続未実装）。
- 遺物rarity段階案: W500 C60/U35/R5、W2500 C40/U45/R15、W5000 C25/U50/R25。中間は下側段階、補間・Luckなし。W100は固定C。
- 未所持種類重み1.5、所持済み1.0（抽選未実装）。
- 遺物12種の過去ドラフト＋攻撃4種は候補集合で最終16種確定ではない。特殊効果の仮数値は個別整理が必要。
- 武器4種: 大剣Overkill Edge、剣Tempering、短剣Thousand Cuts、弓Echo Shot。数値案の採用状態は再確認し、未実装。短剣/弓の追加DamageにCrit/Multi-Crit/Supplementalなし、連鎖なし。
- 槍、Legendary第2固有、遺物生成・振り直しは延期。
